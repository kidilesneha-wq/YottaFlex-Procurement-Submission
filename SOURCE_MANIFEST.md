# Source and provenance manifest

- **Data origin:** Fully synthetic records generated by `generator.py`.
- **Default seed:** `20261022`.
- **External datasets:** None.
- **Personal/confidential data:** None; generated requester and supplier names/emails are fictitious placeholders using `example.test`.
- **Redistribution:** Project code and generated synthetic data are included in this repository package. No third-party dataset licensing or attribution is required for the synthetic records.
- **Reproducibility:** Run `python generator.py --out data/generated --seed 20261022`; checksums are recorded in `data/generated/manifest.json`.
